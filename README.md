# Bottle Cap Inspector 🔍

AI-powered bottle cap inspection system using Python, OpenCV and YOLO.

## Features

- Bottle detection
- Capped bottle detection
- Uncapped bottle detection
- Bounding boxes
- Confidence percentage
- Capped/uncapped counting
- Real-time inspection dashboard
- Warning for uncapped bottles

## Technologies

- Python
- OpenCV
- YOLO
- Ultralytics
- NumPy
